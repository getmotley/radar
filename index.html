How the Radar reads the firehose

GitHub's trending page is a raw popularity list: the same project appears in three languages, and nothing sorts it. The Radar pulls repositories created in the last couple of weeks that are gaining stars, deduplicates them, sorts them into topics, and ranks each by momentum: stars gained, adjusted for how fresh the repo is. It surfaces what's spiking right now. It is not a judgment of code quality, maturity, or whether a repo is production-ready, plenty of these are early experiments.

It refreshes on a schedule. Come back and the board has moved.
