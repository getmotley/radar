TypeScript★ 3.2kMIT571,992 LOCran ✓ npm test exit 127

DeepSeek Harness (dsh) is an open-source agent framework from DeepSeek AI with a desktop app layer on top. The repo is TypeScript-heavy at 566,484 lines with some Python SDK code, Shell, and JavaScript, totaling 571,992 lines across 7,447 files. It uses an "everything is a plugin" architecture powered by Cordis, referencing a paper on spatiotemporal composability. The README is upfront that this is a developer preview and breaking changes are coming. License is MIT.

I cloned it and tried to run it. The README points to `pnpm run dev:desktop` for the desktop app and `npx @deepseek-ai/dsh web` for the web UI. On my machine, pnpm was not found and there was no network access, so neither path worked. The test suite exited 127, meaning the test command itself was not found or not callable in this setup. I checked for entry points and found package.json files across apps/web, apps/desktop, apps/cli, and several vendor packages. The Python SDK under python/sdk had a pyproject.toml declaring `deepseek-harness-sdk` version 0.0.0.dev0, but no importable modules surfaced. The output was blunt: "This is a pnpm-based desktop app. No pnpm/node available, no network. Cannot run pnpm install or pnpm run dev:desktop."

The signals are mixed. 709 test files and CI configured suggest real engineering effort, not a weekend project. The file count and line count back that up. But the 0.0.0.dev0 version on the Python SDK, the developer preview warning, and the fact that I could not get anything to launch in a standard environment tell me this is early. The test suite failing with exit 127 is a practical problem for anyone wanting to validate before adopting.

For developers already invested in the DeepSeek ecosystem or curious about Cordis-based plugin architecture, this is worth tracking. Right now it is not something you can clone and quickly evaluate without a fully configured pnpm and Node environment plus network access. It does not deliver a runnable experience out of the box in a constrained setup.
