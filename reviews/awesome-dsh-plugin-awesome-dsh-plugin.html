This is a curated awesome-list for DeepSeek Harness (dsh) plugins, the kind of directory repo that aggregates community extensions into one browsable place. The problem it solves is discoverability: dsh is a plugin-everything agent framework where models, tools, sandboxes, session storage, UI, and the agent loop itself are all swappable via `dsh.plugin` manifests, and this repo collects installable plugins in one list with bilingual English and Chinese READMEs, a badge system, and a companion marketplace called dsh-market. I could not run it because the venv and pytest setup failed, so this is a static read of the actual source, not a runtime test.

The architecture is a code-generated list, not a hand-maintained markdown file. Plugin entries live in `data/plugins/*.yml` files, and the READMEs are produced by `scripts/generate-readme.mjs`. The Python and Shell line counts (6411 and 233) alongside 6644 lines across 1967 files tell you the bulk is data and generated output, not heavy logic. The one real Python script I read is `scripts/reorder-categories.py`, 40 lines that rewrite the category taxonomy in three places at once: `CAT_IDS` in `scripts/lib/entries.mjs`, and two `categories` blocks in `site/locales.mjs` (one English, one Chinese). It uses `re.findall` with `re.S` to grab the locale blocks, builds dicts from each, asserts the English keys match the target list and the Chinese keys, then rewrites `CAT_IDS` with `re.subn` using `flags=re.M`, replaces the locale blocks in target order, and shells out to `node scripts/generate-readme.mjs` to regenerate everything.

The code quality in that script is decent. It uses assertions to catch taxonomy drift between locales, which is the right instinct for a bilingual generated site. The regex approach is fragile by nature but acceptable here since the file formats are controlled by this same repo. The assert-then-write pattern means a mismatch aborts before corrupting files. Obvious gaps: no license is declared, which matters for a list repo people will fork. Tests exist but only 10 files, and CI is enabled, though I could not observe what the CI actually checks. The script assumes `node` is on PATH with no fallback or version check.

This is for dsh users who want to browse or discover plugins, and for contributors who want to list their own. As a directory it does its job. The generation pipeline is the real product, and `reorder-categories.py` shows it was built carefully enough to handle bilingual taxonomy without silent breakage. I would not judge runtime behavior since I never got the toolchain running, but the source reads as a competently built list generator with sensible guards where it matters. The missing license is the one thing I would fix before relying on it.
