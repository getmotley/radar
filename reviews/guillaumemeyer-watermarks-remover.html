The repository strips AI provenance marks from generated content. It targets three layers: Unicode text hygiene, statistical text rewrite hooks for schemes like MarkLLM and SynthID, and C2PA or AI related metadata embedded in PNG, JPEG, SVG, PDF, DOCX, HTML, and Markdown. The core is pure standard library Python, with optional external probes like exiftool and c2patool used only when present on the system. A 1021 line HTTP service in service/scripts/server.py exposes inspect, detect, and clean endpoints with batch variants capped at 50 files per request via WATERMARKS_MAX_BATCH_FILES. It binds loopback by default and supports an optional bearer API key.

The architecture is split across focused modules. image_meta.py handles raster formats including PNG, JPEG, WebP, AVIF, HEIC, BMP, GIF, and TIFF with classic and BigTIFF support. container_meta.py at 2125 lines covers non raster containers like SVG, PDF, DOCX, ODT, HTML, Markdown frontmatter, and EPUB. It defines a ZipBudgetExceeded exception to refuse zip bombs and catalogs a broad tuple of zip parse errors from BadZipFile through zlib.error so corrupt archives surface correctly. The text benchmark in bench_synthid_text.py orchestrates corpus generation, removal variants, and measurement of clear rate, score suppression, lexical divergence, and cost. It imports SCHEMES from detect_text_watermark and reuses _lexical_divergence from rewrite_text, showing real internal code sharing rather than duplicated logic.

Code quality is strong from what I can see. Docstrings are specific about failure modes and name the exact exceptions a corrupt zip can raise. The optional SynthID scorer runs as a sidecar controlled by WATERMARKS_SYNTHID_SCORER_URL, keeping noncommercial upstream code out of the published image. CtrlRegen gets higher resource limits through ctrlregen_preexec_fn with env overridable caps at 32 GB address space. Batch endpoints isolate per file failures as ok:false with an error string rather than aborting the whole request. The project has 41 test files, CI is enabled, and it is MIT licensed across 150 files totaling 26562 lines with Shell at 615 lines and Python at 25947.

This is for developers building pipelines that need to inspect or remove AI provenance marks at scale. The standard library approach means minimal dependencies, and the HTTP service makes it callable from any language. The source I read is organized, defensive about parsing failures, and honest about optional tooling. I could not run it, but the code itself is credible and carefully constructed.
