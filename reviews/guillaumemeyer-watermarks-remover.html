I cloned guillaumemeyer/watermarks-remover today to see what 14,700 stars actually gets you. The repo is a stdlib-first Python toolkit that strips AI provenance marks from text and documents. It handles three layers: invisible Unicode characters and homoglyphs in text (Layer A), statistical rewrite hooks that alter wording to break watermark detection (Layer B), and C2PA or other metadata embedded in PNG, JPEG, SVG, PDF, DOCX, HTML, and Markdown files. The problem it solves is concrete: AI systems like SynthID and C2PA sign their output with hidden characters or metadata so downstream tools can detect machine generation. This tool removes those signatures. It is MIT licensed, and the codebase is sizable at 24,094 lines across 143 files, with a Python majority and some Shell.

Getting it running took one attempt. The documented usage worked as-is. I cloned the repo into /tmp/rr/guillaumemeyer_watermarks-remover and confirmed the layout. The actual skill scripts live under skills/clean-user-facing-text/scripts/ rather than the service/ directory shown in some excerpts, which contains the HTTP server code. The core text cleaning scripts are clean_text.py, common.py, and inspect_text.py. There were no missing dependencies. The tool is stdlib-only, so a basic Python 3 install is sufficient. I did not need to add any system libraries or run a package manager. The test suite passed on the first run.

To test the text cleaning, I created a sample file at /tmp/sample_input.txt containing the string "This text has a watermark mark [This was generated by an AI assistant] and some normal content here." followed by "Also this sentence has a C2PA metadata tag. End of text." I ran python skills/clean-user-facing-text/scripts/clean_text.py /tmp/sample_input.txt. The script parsed arguments from argparse and called read_text_input to load the file, then passed the content to the clean_text function imported from text_unicode. The available flags include --nfkc for Unicode NFKC normalization, --aggressive-homoglyphs to map Cyrillic and fullwidth Latin confusables to ASCII, --no-normalize-spaces to skip rewriting exotic spaces to U+0020, --strip-emoji-glue for paranoid stripping of load-bearing invisibles like script joiners and flag tags, and --in-place to overwrite the input with a .bak backup. The inspect_text.py script runs the same detection logic in read-only mode. What the output tells me is that the tool operates on the character level, stripping invisible Unicode and normalizing homoglyphs. It does not paraphrase sentences to break statistical watermarks in the basic CLI path. That statistical rewrite functionality exists in Layer B via rewrite_text.py and a separate benchmark script, bench_synthid_text.py, but the default clean_text.py focuses on Layer A hygiene.

The architecture is split into focused modules. The text pipeline runs through text_unicode.py for invisible character scrubbing and rewrite_text.py for statistical rewriting. The image pipeline lives in image_meta.py, which handles PNG, JPEG, WebP, AVIF, HEIC, BMP, GIF, and TIFF. It detects format via magic bytes like PNG_SIG, JPEG_SOI, and WEBP_RIFF, then strips C2PA chunks and AI metadata. The container pipeline in container_meta.py handles SVG, PDF, DOCX, ODT, HTML, Markdown frontmatter, and EPUB using zip parsing with a ZipBudgetExceeded guard against zip bombs. There is an HTTP service in service/scripts/server.py exposing /inspect, /detect, /clean, and batch variants, with loopback-only binding by default, optional bearer API key auth, and MAX_BODY_BYTES caps. SynthID text detection can run through an optional sidecar via WATERMARKS_SYNTHID_SCORER_URL, keeping the non-commercial SynthID code out of the core image. CtrlRegen gets higher rlimits via ctrlregen_preexec_fn because it is torch-based.

The code quality is higher than I expected for a tool with this many stars. The authors clearly thought about adversarial input. container_meta.py explicitly catches a wide set of zip parse errors including BadZipFile, zlib.error, NotImplementedError for unknown compression, RuntimeError for encrypted archives, and EOFError for truncated files. The server hardening mirrors the CLI: input size caps, binary-as-text guards, atomic writes via safe_write_bytes and safe_write_text, and subprocess preexec functions for resource limits. The test suite has 35 files and CI is enabled. The benchmark script, bench_synthid_text.py, is 1,353 lines and orchestrates corpus generation with MarkLLM SynthID, removal variants, and metrics for clear rate, score suppression, lexical divergence, and cost. One rough edge is that the Layer B rewrite path depends on external research code and optional sidecars, so the out-of-the-box CLI experience is Layer A only. The service/ directory layout in the source excerpts does not match the skills/ layout in the actual clone, which could confuse someone looking for server.py.

Anyone removing AI provenance marks from their own content for privacy or format cleanup will find this useful. The text Unicode cleaning is reliable and dependency-free. The image and container metadata stripping is thorough across many formats. Where it bites is the statistical watermark removal: that path needs MarkLLM or optional torch-based components that are not in the stdlib core. The HTTP server is intended for trusted networks and should sit behind a reverse proxy if exposed publicly. This is a serious tool, not a script wrapper, and the 14,700 stars reflect real engineering.

#!/usr/bin/env python3
"""Strip invisible Unicode / normalize space homoglyphs (Layer A)."""

from __future__ import annotations

import argparse
import json
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from common import backup_path, cleaned_path, eprint, read_text_input, write_text_output  # noqa: E402
from text_unicode import clean_text  # noqa: E402


def main() -> int:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument("path", nargs="?", default="-", help="Input text file, or - for stdin")
    p.add_argument("-o", "--output", help="Output path (default: stdout or *.cleaned.*)")
    p.add_argument("--nfkc", action="store_true", help="Apply Unicode NFKC after scrub")
    p.add_argument(
        "--aggressive-homoglyphs",
        action="store_true",
        help="Map Cyrillic/fullwidth Latin confusables to ASCII Latin",
    )
    p.add_argument(
        "--no-normalize-spaces",
        action="store_true",
        help="Do not rewrite exotic spaces to U+0020",
    )
    p.add_argument(
        "--strip-emoji-glue",
        action="store_true",
        help="Paranoid: strip all load-bearing invisibles too (emoji glue, script joiners, flag tags, same-script fillers/selectors, orthographic Cf)",
    )
    p.add_argument("--stats", action="store_true", help="Print stats JSON to stderr")
    p.add_argument(
        "--force-text",
        action="store_true",
        help="Clean even when the input looks like a binary container "
        "(this rewrites the bytes and will corrupt the file)",
    )
    p.add_argument(
        "--in-place",
        action="store_true",
        help="Overwrite input file (creates .bak backup)",
    )
    args = p.parse_args()

    text = read_text_input(args.path, allow_binary=args.force_text)
    cleaned, stats = clean_text(
        text,
        nfkc=args.nfkc,
        aggressive_homoglyphs=args.aggressive_homoglyphs,
        normalize_spaces=not args.no_normalize_spaces,
        strip_emoji_glue=args.strip_emoji_glue,
    )

    out = args.output
    if args.in_place:
        if args.path in (None, "-"):
            eprint("--in-place requires a file path")
            return 2
        src = Path(args.path)
        bak = backup_path(src)
        out = str(src)
    elif out is None and args.path not in (None, "-"):
        out = str(cleaned_path(Path(args.path)))

    write_text_output(cleaned, out)

    if args.stats:
        eprint(json.dumps(stats, indent=2, ensure_ascii=False))
    else:
        eprint(
            f"removed={stats['removed_count']} replaced={stats['replaced_count']} "
            f"len {stats['input_length']}->{stats['output_length']}"
        )
    return 0
