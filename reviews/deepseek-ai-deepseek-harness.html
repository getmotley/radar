I cloned deepseek-ai/deepseek-harness today. It is a TypeScript agent framework from DeepSeek built on the "everything is a plugin" principle, powered by a library called Cordis which has an accompanying paper on spatiotemporal composability. The repo is large, 569789 lines across 7411 files, with TypeScript making up the vast majority of the codebase. It carries an MIT license, has 700 test files, and CI is enabled. The README is in Chinese and states the project is in a developer preview stage with breaking changes expected.

Running it was a mess. The README says to run `npx @deepseek-ai/dsh web` to launch a Web UI. Our test suite failed with exit code 127, which usually means a command was not found. When we tried `npx @deepseek-ai/dsh --help`, we got `sh: 1: dsh: not found`. Trying `pnpm dsh --help` returned `pnpm: command not found`. The `which dsh` command also failed. We checked for a Python SDK import and got `python: command not found`. The only thing that worked was `node --version`, which showed v20.19.2. The demo script we ran did not successfully execute the tool at all.

The signals here are mixed. The repo has real substance: 700 test files, CI enabled, and a massive TypeScript codebase. But it is in developer preview and that shows. The tool did not run for us. Exit code 127 means the test command itself was missing or misconfigured. The npx command failed to find the dsh binary. For a project with 102349 stars, the onboarding experience is rough.

If you want a stable agent framework today, skip this. It is a developer preview that breaks compatibility and currently fails basic execution. Developers who want to track DeepSeek's plugin architecture research might watch it, but nobody should depend on it for production work right now.
